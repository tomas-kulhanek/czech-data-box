# WSDL definice ISDS

Zdroj: Provozní řád ISDS 26. 06. 2026, příloha 2 (WSDL verze 3.11), klasifikace Veřejný dokument.

Soubory slouží jako podklad pro matici pokrytí (`php tools/wsdl-coverage.php`) — knihovna z nich negeneruje kód.

Záměrně zde nejsou WSDL služeb mimo záběr knihovny: `ChangePassword.wsdl` (asws), `SetConcept.wsdl`
a `ExtWs.wsdl` (odesílací brána). Důvody jsou popsané v sekci „Mimo záběr knihovny“ v [README.md](../../../README.md).
